## 🎯 1. Number Guessing Game

A simple guessing game where the player gets **3 chances** to guess a randomly generated number.

### Features
- Random number generation
- 3 chances
- Too high / Too low hints
- Congratulations message when the player wins

### How to Run

```bash
python number_guessing_game.py

## 🎯 2. Stone Paper Scissors

3 rounds

Player and computer choices are revealed together
Player wins are counted
2 or more wins → Good Job 🎉

python stone_paper_scissors.py
